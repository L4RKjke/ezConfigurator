Каталог видеопередатчиков

Внутренняя утилита мейнтейнера. Добавляет записи в vtxCatalog/catalog.json и фото в vtxCatalog/photos/. Работает в Chrome / Edge (File System Access API).
Таблицу можно вставлять любым текстом — в JSON попадут только строки vtxtable, строки set/save/#-комментарии игнорируются. Полоса и канал в записи всегда фиксируются как 1/1.
Если название уже есть в каталоге — существующая запись будет заменена.
